# 首版完成度与并行工作

更新：2026-09-23。这里区分“功能已接通”和“产品指标已验收”；后者不能由模拟事件、标定拟合或单次演示替代。

| 实施阶段 | 当前状态 | 尚需完成 |
|---|---|---|
| 1. 接入与能力诊断 | Windows 一键启动、原生 X4 Air 采集、960×480 实时 ERP、AAC 解码、相机/电脑麦克风来源显示均已工作。相机内置麦克风的强降风噪模式实测同源双声道；全景声模式实测 48kHz 四声道，四方位及转动标定通过。 | 弱降风噪、立体声与全景声的同条件声音质量对照；真实 USB 拔插后的无人操作恢复验收。 |
| 2. 可观看闭环 | 本地服务、两个 WebSocket、全屏第一视角 HUD 与双栏调试已接通；真实相机约 30 FPS。当前版本再次完成 602 秒连续采集：299/299 次有效，FPS 中位数 30.3；此前的三次起停与采集进程故障注入也已通过。画面失效不会自动变成无标记回放。 | 真实 USB 拔插后的无人操作恢复尚未验收；多机型/更多电脑不在首版已验证范围。 |

| 4. 演示与验证 | 最近事件、录制回放、模拟 UI、报告导出、安装/构建/启动脚本已具备。115 项自动测试通过；40 种 HUD 布局的中央区域文本/卡片无遮挡比例最小 80.86%。可恢复的现场试次 CLI、只读录音延迟诊断、可校验的本地源码 ZIP 均已完成。 | 240 次独立正样本与 10 分钟安静负样本尚未执行；真实发声到 HUD 的 P95 延迟尚未测量；对外发布前仍须确定项目许可证及第三方分发边界。 |

因此，**工程端到端链路已可演示，但四项产品数值目标（危险声召回率、独立现场方位误差、发声到 HUD P95、安静误报率）均未得到完整现场验收**。模型单次推理约数毫秒不等于发声到显示的延迟。此前方向采样包含用于确定声道映射的标定集，不能再充作独立准确率样本。

并行分支从已测试的集成基线 `a917479` 分出；互相独立的工作树位于本机 `.worktrees/`。三项已分别提交，并合入 `codex/mvp-integration`：

| 分支 | 范围 | 可验证产物 |
|---|---|---|
| `codex/latency-telemetry`（`e44491a`） | 区分模型耗时与回放链路耗时，保留真实发声到 HUD 指标的现场边界 | [离线诊断](latency-diagnostics.md)、测试、延迟字段；集成提交 `a6698d4` |
| `codex/field-trials`（`b04ee87`） | 让 240 次现场试验可恢复、可校验地逐项填写 | [现场流程](field-testing.md)、CLI、测试；集成提交 `0902eb0` |
| `codex/source-release`（`3dd96d7`） | 建立排除 SDK、权重和个人录制素材的源码包检查 | [源码包说明](release.md)、哈希清单、测试；集成提交 `7d44c2c` |

集成后的完整测试为 115 项通过。现场工作表仍为 0/240，安静负样本为 0/10 分钟。对 9.984 秒已有真实人声录音，离线回放诊断测得模型推理 P95 7.75 ms、最后 PCM 块时间戳到事件 P95 22.81 ms、到本地 WebSocket 收件 P95 122.02 ms（8/8 次事件更新收到）。这些数值不含物理发声起点、相机采集和浏览器绘制，**不能代替发声到 HUD 的 P95 验收**。现场声音摆放、标注与外部同钟录像仍需操作者配合。
