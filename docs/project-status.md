# 首版完成度与并行工作

更新：2026-09-23。这里区分“功能已接通”和“产品指标已验收”；后者不能由模拟事件、标定拟合或单次演示替代。

| 实施阶段 | 当前状态 | 尚需完成 |
|---|---|---|
| 1. 接入与能力诊断 | Windows 一键启动、原生 X4 Air 采集、960×480 实时 ERP、AAC 解码、相机/电脑麦克风来源显示均已工作。相机内置麦克风的强降风噪模式实测同源双声道；全景声模式实测 48kHz 四声道，四方位及转动标定通过。 | 弱降风噪、立体声与全景声的同条件声音质量对照；真实 USB 拔插后的无人操作恢复验收。 |
| 2. 可观看闭环 | 本地服务、两个 WebSocket、全屏第一视角 HUD 与双栏调试已接通；真实相机约 30 FPS。曾完成 602 秒连续采集、三次起停与采集进程故障注入；画面失效不会自动变成无标记回放。 | 在当前完整版本上复跑长时稳定性和真实拔插场景；多机型/更多电脑不在首版已验证范围。 |
| 3. 算法闭环 | 本地 YAMNet 输出 10 组声音类别，YOLOv8n/DirectML 输出视觉候选；全景声粗方位、低置信度降级、类别/时间匹配、事件优先级与过期清除已实现。真实人声、相机音频方位和 HUD 图标/声纹已联调。 | 鸣笛、警笛、铃声等危险类别在真实现场的召回/误报；不同背景声、多声源、运动和风噪下的方向覆盖率及错误率。现有标定平均 9.8°、最大 16.0°只描述标定集。 |
| 4. 演示与验证 | 最近事件、录制回放、模拟 UI、报告导出、安装/构建/启动脚本已具备。86 项自动测试通过；40 种 HUD 布局的中央区域文本/卡片无遮挡比例最小 80.86%。 | 240 次独立正样本与 10 分钟安静负样本尚未执行；真实发声到 HUD 的 P95 延迟尚未测量；源码发布包与许可证边界正在并行整理。 |

因此，**工程端到端链路已可演示，但四项产品数值目标（危险声召回率、独立现场方位误差、发声到 HUD P95、安静误报率）均未得到完整现场验收**。模型单次推理约数毫秒不等于发声到显示的延迟。此前方向采样包含用于确定声道映射的标定集，不能再充作独立准确率样本。

并行分支从已测试的集成基线 `a917479` 分出；互相独立的工作树位于本机 `.worktrees/`：

| 分支 | 范围 | 可验证产物 |
|---|---|---|
| `codex/latency-telemetry` | 区分模型耗时与回放链路耗时，保留真实发声到 HUD 指标的现场边界 | 诊断脚本、测试、延迟字段说明 |
| `codex/field-trials` | 让 240 次现场试验可恢复、可校验地逐项填写 | CLI、自动测试、填写流程 |
| `codex/source-release` | 建立排除 SDK、权重和个人录制素材的源码包检查 | 本地源码包、哈希清单、许可事项说明 |

这些分支完成后要逐个审查并集成，不能把分支存在本身视为功能完成。现场声音摆放、标注与外部同钟录像仍需操作者配合。
