## SDK 实测修正

1. **回调像素标记与头文件不符。** 实际 `format=0`，960×480，stride=3840，只有一个平面，RGBA alpha 为 255。原生进程对该具体布局做受限兼容；标准 RGBA 标记 26 仍支持，不能把真正的平面 YUV 当 RGBA。
2. **时间戳单位与头文件不符。** 音频及拼接回调均按毫秒递增，而头文件描述微秒。采用实测单位，不直接依赖注释。内部兼容字段 `camera_us` 保留原始 SDK tick，真实单位记录在 `clock_diagnostics`，主处理使用对齐后的主机秒数。
3. **直播音频声道取决于机身收音模式。** 强降风噪模式曾实测同源双声道，不能独立定位；切换全景声后实测四声道，通过四方位与转动验证后才启用声学粗方位。标定失配、低置信度或多类别声音无法归属时仍保留方向未知；唯一、时间与类别匹配的视觉目标可显示明确标记的候选方向。
4. **编解码运行库。** Python 侧直接使用 PyAV 的 FFmpeg 库，不额外依赖系统 `ffmpeg.exe`；C++ 侧不引入 OpenCV 开发包。
