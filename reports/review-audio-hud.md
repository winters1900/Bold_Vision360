# 声音方向与 HUD 修复记录

本次 Review（2026-09-22 至 2026-09-23）针对「无法识别声音方向、没有声纹和三棱锥」展开。**已修复显示链路；最初双声道输入不具备独立定位条件，后续切换全景声并通过四方位及转动验证后启用了音频方向。** 最新证据、定位修复与误差限制见 [空间音频标定实测](spatial-calibration.md)，下文保留初次 Review 的输入和测试记录。

## 发现与处理

| 问题 | 原因 | 处理 |
|---|---|---|
| 未知方向时没有声纹和图标 | HUD 遇到 `angle=null` 提前返回，只显示文字和扬声器 | 未知方向卡片保留三棱锥和实测波形，同时写明没有候选或多个候选；不画确定的方位扇区 |
| 图标不符合效果图 | 原图标为 CSS 渐变平面菱形 | 使用 SVG 三个独立三角面，红、绿、金三色及白色棱线；有方位证据时随视角转动，不表达高度 |
| 声纹不明显且不是真实形状 | 原波形为固定正弦形状乘单个音量值 | 按 PCM 每 20ms 计算能量，传输 64 点包络，绘制边缘填充波形；静音不制造纹理，无音频时只保留轻微提示脉冲 |
| 收到声音但界面像没工作 | 只有分类通过去抖后才显示任何声音反馈 | 未确认类别时显示实际音频活动；模型不可用时准确显示状态 |
| 已有相机流无法独立定位 | AAC 标记 2 声道，但录制 PCM 两路相同 | 增加在线声道相关性、差异能量比、有效样本时长及定位能力诊断，支持导出；不把两路相同数据用于虚假定位 |
| 视觉候选切换时箭头指向无目标的中间角度 | 沿用上一个候选的平滑窗口 | 候选身份/证据改变或方向丢失时重置平滑窗口 |
| 方向文字在扇区边界跳动 | 前端忽略后端带滞回的 `sector` | 标签使用后端扇区并按当前视角转换；图标不做跨 360° 的 CSS 长路径旋转 |

## 输入能力证据

对本机 `20260922-225114`、`20260922-231148`、`20260922-232224-8ced` 三个录制会话，分别均匀抽取约 100 个 PCM 块，总计 104448、128000、128000 个双声道采样点。均测得声道相关性 **1.0**、左右差值 RMS **0.0**。这证明被抽样的输入没有可用声道差，不代表相机所有模式都无法输出空间音频。

解码通路直接保留 AAC 输出的各声道，没有将单声道复制成双声道。新增独立左右信号 → 实际 AAC 编码 → 本项目解码的回归测试，确认不会丢失左右差异。

在线诊断使用最近约 1 秒的信号统计，至少半秒有效输入后检查声道结构；差异能量比低于 `1e-6` 判为近似双声道同源，静音不判为同源。该诊断只描述输入结构，不推断声源方位。视觉方向仍要求唯一、类别匹配、时间差小于 500ms 的候选；多人/多车时保留未知，并给出原因。

官方机身操作为顶部下滑 → 音频设置；X4 Air 支持立体声、降风噪、人声增强与 360 音频。官方明确 360 音频用于全景视频录制，不能据此认定 SDK 直播也有 Ambisonic 输出。[官方音频说明](https://onlinemanual.insta360.com/x4air/en-us/operating-tutorials/step/audio)

当前所用 CameraSDK 头文件 `LiveStreamParam` 提供音频开关、采样率、码率及直播开关，没有声道数或空间模式参数。需要核对机身模式后重连，检查实际 PCM；四声道仍须通过已有四方位与转动标定才能启用方向。

## 验证与边界

- 47 项 Python 自动测试通过，Ruff 检查、TypeScript 检查和 Vite 生产构建通过。新增覆盖独立 AAC 声道、交错/平面格式、同源双声道、静音、反相信号能量、音频中断清除、候选切换及诊断导出。
- 实际录制回放用于验证波形随 PCM 更新、三棱锥显示、同源双声道诊断；不是新现场声源定位测试。
- 浏览器覆盖 1920×1080、1366×768，全屏与双栏、八方向及未知方向、查看方向转换、0°/360°、扇区文字滞回、无音频时无伪造波形、事件清除。定向事件为明确标记的模拟，仅验证 UI。
- 本机证据：`local-audio-hud-tests.json`、`local-audio-replay-1920.png`、`local-audio-replay-1366.png`、`local-audio-debug-1366.png`、`local-audio-ribbon-simulation.png`。素材与诊断中的现场数据不提交 Git。
- 当前新增界面和工程验证不能替代 240 次现场测试、真实方向误差或端到端延迟验收；原报告中未验收项保持未验收。
